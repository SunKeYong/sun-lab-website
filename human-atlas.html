ABOUT THE PROJECT

A window into human
cell-type regulation.

This resource provides a genome browser for human cell-type chromatin accessibility. The current preview connects the C6.2 Cardiomyocytes bigWig to the hg38 reference genome.

01 / EXPLORE

Start with a gene

Search gene symbols or coordinates. Gene locations come from the supplied hg38 annotation.

02 / COMPARE

Choose cell types

Toggle signal tracks. The project has 131 cell types; one is connected in this preview.

03 / INSPECT

Read the landscape

Pan and zoom through the genome, inspect transcript structures and export the current view as SVG.
