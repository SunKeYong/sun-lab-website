ABOUT THE PROJECT

A window into human
cell-type regulation.

This resource provides a genome browser for human cell-type chromatin accessibility. The full catalog connects 131 cell-type bigWigs from the laboratory cluster to the hg38 reference genome.

01 / EXPLORE

Start with a gene

Search gene symbols or coordinates. Gene locations come from the supplied hg38 annotation.

02 / COMPARE

Choose cell types

Select from all 131 cell types. Display multiple tracks together using a shared, independent or fixed signal scale.

03 / INSPECT

Read the landscape

Pan and zoom through the genome, inspect transcript structures and export the current view as SVG.
