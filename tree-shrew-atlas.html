ABOUT THE PROJECT

Two cell types.
One shared genomic view.

This resource provides a genome browser for tree shrew cell-type chromatin accessibility. This preview connects atrial and ventricular cardiomyocyte bigWigs to the TS_3.0 reference genome. Both signals share the same genomic coordinates and are displayed together by default.

01 / EXPLORE

Start with a gene

Search gene symbols or coordinates. Gene locations come from the supplied TS_3.0 annotation.

02 / COMPARE

Choose cell types

Display both cell types simultaneously, or hide either track. Shared autoscaling uses the same y-axis range across the visible signal tracks.

03 / INSPECT

Read the landscape

Pan and zoom through the genome, inspect transcript structures and export the current view as SVG.
